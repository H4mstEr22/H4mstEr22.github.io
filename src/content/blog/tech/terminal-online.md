信号接通。这里是我的个人终端，第一篇日志就从它本身说起。

## 为什么要自己搭

现成的博客平台很多，但我想要一个**完全由自己控制**的地方：内容是纯文本 Markdown，样式想怎么改就怎么改，托管免费，换平台时直接把文件夹带走就行。

## 技术选型

| 组件 | 选择 | 理由 |
| --- | --- | --- |
| 框架 | Astro | 静态输出、零 JS 默认、Markdown 一等公民 |
| 托管 | GitHub Pages | 免费，和仓库天然绑定 |
| 部署 | GitHub Actions | push 到 `main` 后自动构建发布 |
| 字体 | Barlow / JetBrains Mono | 工业感的无衬线 + 清晰的等宽 |

整个站点构建后是纯静态 HTML，首页几乎不需要 JavaScript——时钟、主题切换和一点入场动画是仅有的脚本。

## 视觉方向

视觉上参考了工业科幻的界面语言：

- **信号黄 + 墨黑**：唯一的强调色，只用在需要被看见的地方
- **警示条纹、裁切角、定位环**：来自工业设备和战术终端的装饰元素
- **等宽小标注**：`[ 01 ]`、`LOG.0001` 这类编号让信息像档案一样被归类
- **浅色 / 深色**：浅色是白天的工业场地，深色是夜间值班的终端

> 所有图形都是用 CSS 和 SVG 画出来的，没有用任何图片素材。
